## 项目概述

### 技术栈

- **前端框架**: Vue 3 (Composition API + `<script setup>`)
- **桌面框架**: Electron 32.2.7
- **浏览器自动化**: Playwright
- **状态管理**: Pinia
- **UI组件库**: Element Plus
- **构建工具**: Vite
- **路由**: Vue Router (Hash模式)

### 项目规模

- **总源文件**: 80+ 个
- **核心代码**: 2000+ 行
- **IPC通道**: 40+ 个
- **错误处理**: 138+ 个 try/catch 块

### 核心功能模块

1. **浏览器实例管理** - 创建、启动、停止、删除指纹浏览器
2. **内核版本管理** - 下载、安装、删除 Chromium 内核
3. **指纹注入** - 自动注入指纹脚本规避检测
4. **历史记录管理** - 持久化浏览历史
5. **凭证管理** - 保存和自动填充密码
6. **邮件管理** - Gmail 集成
7. **自动更新** - 基于 GitHub Releases

## IPC通信架构

### 双模式通信

项目采用两种 IPC 通信模式：

#### 1. Request-Response 模式（invoke/handle）

**用途**: 需要返回值的操作（CRUD、查询等）

**流程**:
```
渲染进程                主进程
   │                      │
   │  invoke(channel)     │
   ├─────────────────────>│
   │                      │ 执行处理器
   │                      │ (ipcMain.handle)
   │  <返回结果>          │
   │<─────────────────────┤
   │                      │
```

**代码示例**:

```javascript
// 渲染进程 (preload/browserManager.js)
createBrowser: (config) => ipcRenderer.invoke('browser:create', config)

// 主进程 (main/browserManager.js)
ipcRegistry.registerHandlers({
  'browser:create': async (event, config) => {
    const instance = new BrowserInstance(config);
    await instance.launch();
    return { success: true, id: instance.id };
  }
});
```

**已注册的 40+ 通道**:
- `browser:create`, `browser:close`, `browser:delete`
- `browser:get-all`, `browser:get-status`
- `browser-core:download`, `browser-core:cancel-download`
- `update:check`, `update:download`
- `email:auth`, `email:get-messages`

#### 2. Event 模式（send/on）

**用途**: 主进程主动推送事件（进度更新、状态变化）

**流程**:
```
主进程                  渲染进程
   │                      │
   │  send(channel, data) │
   ├─────────────────────>│
   │                      │ 触发监听器
   │                      │ (ipcRenderer.on)
   │                      │
```

**代码示例**:

```javascript
// 主进程 (main/ipc/emitter.js)
class IPCEmitter {
  send(channel, data) {
    BrowserWindow.getAllWindows().forEach(win => {
      win.webContents.send(channel, data);
    });
  }
}

// 使用
ipcEmitter.send('browser-download-progress', {
  id: 'browser-123',
  progress: 45.2,
  speed: '2.5 MB/s'
});

// 渲染进程 (composables/useDownloadListeners.js)
globalIpcManager.register('browser-download-progress', (data) => {
  const store = useUserStore();
  store.updateDownloadProgress(data.id, data.progress);
});
```

**事件通道**:
- `browser-download-start/progress/complete/error`
- `browser-status-changed`
- `update-available`, `update-downloaded`
- `log-message`

### IPC 注册中心设计

**核心类**: `IPCRegistry` ([electron/main/ipc/registry.js](electron/main/ipc/registry.js))

**特点**:
1. **集中管理**: 所有 IPC 处理器在一处注册
2. **统一错误处理**: 自动捕获异常并返回标准格式
3. **日志记录**: 自动记录所有 IPC 调用

```javascript
class IPCRegistry {
  registerHandlers(handlers) {
    Object.entries(handlers).forEach(([channel, handler]) => {
      ipcMain.handle(channel, async (event, ...args) => {
        try {
          logger.info(`IPC调用: ${channel}`);
          return await handler(event, ...args);
        } catch (error) {
          logger.error(`IPC错误 [${channel}]:`, error);
          return { success: false, error: error.message };
        }
      });
    });
  }
}
```

### Preload 安全隔离

**设计原则**: 最小权限暴露

```javascript
// electron/preload/index.js
contextBridge.exposeInMainWorld('ipcRenderer', {
  // 只暴露必要的API，不暴露原始 ipcRenderer
  ...browserManagerAPI,
  ...updateManagerAPI,
  ...emailManagerAPI,
  ...loggerManagerAPI
});
```

**优势**:
- 防止渲染进程直接访问 Node.js API
- 类型安全（可配合 TypeScript）
- 易于维护和审计

### 优秀实践

#### 1. Composables 模式（⭐⭐⭐⭐⭐）

**useIpcListener** ([src/composables/useIpcListener.js](src/composables/useIpcListener.js))

**问题**: IPC 监听器需要在组件卸载时清理，避免内存泄漏

**解决方案**:
```javascript
export function useIpcListener(channel, callback) {
  const cleanup = window.ipcRenderer.on(channel, callback);

  // 自动清理
  onUnmounted(() => {
    cleanup();
  });

  return cleanup;
}

// 使用
<script setup>
import { useIpcListener } from '@/composables/useIpcListener';

useIpcListener('browser-status-changed', (data) => {
  console.log('状态变化:', data);
});
// 组件卸载时自动移除监听器
</script>
```

**useApiHandler** ([src/composables/useApiHandler.js](src/composables/useApiHandler.js))

**问题**: API 调用需要统一的错误处理和加载状态

**解决方案**:
```javascript
export function useApiHandler() {
  const loading = ref(false);

  const execute = async (apiCall, options = {}) => {
    loading.value = true;
    try {
      const result = await apiCall();
      if (options.successMessage) {
        ElMessage.success(options.successMessage);
      }
      return result;
    } catch (error) {
      ElMessage.error(error.message || '操作失败');
      throw error;
    } finally {
      loading.value = false;
    }
  };

  return { loading, execute };
}

// 使用
const { loading, execute } = useApiHandler();
const handleDelete = () => {
  execute(
    () => browserAPI.delete(id),
    { successMessage: '删除成功' }
  );
};
```

**useSearchTable** ([src/composables/useSearchTable.js](src/composables/useSearchTable.js))

**问题**: 多个页面都有搜索表格，逻辑重复

**解决方案**:
```javascript
export function useSearchTable(fetchDataFn) {
  const tableData = ref([]);
  const loading = ref(false);
  const searchForm = reactive({
    keyword: '',
    page: 1,
    pageSize: 20
  });

  const search = async () => {
    loading.value = true;
    try {
      const { data } = await fetchDataFn(searchForm);
      tableData.value = data.list;
    } finally {
      loading.value = false;
    }
  };

  const reset = () => {
    Object.assign(searchForm, { keyword: '', page: 1 });
    search();
  };

  return { tableData, loading, searchForm, search, reset };
}

// 使用
const { tableData, loading, search, reset } = useSearchTable(browserAPI.getList);
```

```javascript
// 防抖
export function debounce(fn, delay = 300) {
  let timer = null;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

// 节流
export function throttle(fn, delay = 300) {
  let last = 0;
  return function(...args) {
    const now = Date.now();
    if (now - last > delay) {
      last = now;
      fn.apply(this, args);
    }
  };
}

// 格式化文件大小
export function formatBytes(bytes) {
  if (bytes === 0) return '0 B';
  const k = 1024;
  const sizes = ['B', 'KB', 'MB', 'GB'];
  const i = Math.floor(Math.log(bytes) / Math.log(k));
  return (bytes / Math.pow(k, i)).toFixed(2) + ' ' + sizes[i];
}
```

## 稳定性分析

### 错误处理机制（⭐⭐⭐⭐）

#### 1. 多层错误捕获

**层级结构**:
```
应用层（Vue Error Handler）
    ↓
API层（Axios Interceptor）
    ↓
IPC层（Registry统一捕获）
    ↓
业务层（try/catch）
    ↓
系统层（process.on('uncaughtException')）
```

**实现**:

```javascript
// 1. Vue 全局错误处理 (main.js)
app.config.errorHandler = (err, instance, info) => {
  console.error('Vue错误:', err, info);
  ElMessage.error('应用错误，请刷新页面');
};

// 2. Axios 拦截器 (utils/request.js)
request.interceptors.response.use(
  response => { /* ... */ },
  error => {
    if (error.response?.status === 401) {
      router.push('/login');
    } else if (error.response?.status === 500) {
      ElMessage.error('服务器错误');
    }
    return Promise.reject(error);
  }
);

// 3. IPC 统一捕获 (ipc/registry.js)
ipcMain.handle(channel, async (event, ...args) => {
  try {
    return await handler(event, ...args);
  } catch (error) {
    logger.error(`IPC错误 [${channel}]:`, error);
    return { success: false, error: error.message };
  }
});

// 4. 业务层 (browserManager.js)
async createBrowser(config) {
  try {
    const instance = new BrowserInstance(config);
    await instance.launch();
```

```javascript
class Cache {
  constructor(ttl = 60000) {
    this.cache = new Map();
    this.ttl = ttl;
  }

  set(key, value) {
    this.cache.set(key, {
      value,
      expiry: Date.now() + this.ttl
    });
  }

  get(key) {
    const item = this.cache.get(key);
    if (!item) return null;

    if (Date.now() > item.expiry) {
      this.cache.delete(key);
      return null;
    }

    return item.value;
  }
}

// 使用
```
