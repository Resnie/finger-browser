# Mac / Windows 同一浏览器环境同步验收

2026-10-13，使用 Mac 打包应用、Windows 实机安装包、隔离测试账号与本地验收后端，验证同一 UUID 的环境。**关闭后接力可以恢复同一配置与测试数据；两端各自运行时不会实时合并；当前实际指纹在两端不同，不能计为“网站识别为同一环境”通过。**

## 实测结果

| 操作 | 结果 |
| --- | --- |
| Mac 创建默认开启自动指纹的 140 / 144 环境，Windows 查找并打开 | 相同 UUID，配置 SHA-256 相同 |
| Mac 保存并关闭 → 全新 Windows 本地档案恢复 | 两个环境均通过 |
| Windows 修改、保存并关闭 → 全新 Mac 本地档案恢复 | 两个环境均通过 |
| 恢复 Cookie 和受控网站登录态 | HttpOnly Cookie 与服务端 `/me` 均通过 |
| 恢复 localStorage、sessionStorage、IndexedDB、OPFS、CacheStorage | 双向通过，OPFS 另含中文嵌套目录、二进制文件和空目录 |
| 历史与应用保存的测试凭据 | 双向恢复通过 |
| Mac 保持打开时，Windows 打开同一个 140 环境 | 两端同时运行相同 UUID，各有独立 Chromium 进程 |
| Windows 保存新值后，Mac 继续读取已经打开的网页 | Mac 仍保留旧值，没有实时合并 |
| Mac 随后保存旧版本数据 | CAS 拒绝旧版本写入；新云端数据未被覆盖；Mac 本地加密 outbox 保留 |
| 同一环境在原设备重复采样及返回 Mac | 指纹稳定 |
| 同一 UUID 在 Mac / Windows 采样 | 指纹不同，未通过跨系统身份一致性 |

两个环境分别为 `efc200f1-f767-40b5-98d4-c00166184ae0`（140.0.7259）与 `1ef8b68e-65e8-4216-8069-67e03db1676f`（144.0.7500）。并发测试中 Mac outbox 的版本为 25，较新云端版本为 28；旧端显式操作收到“浏览器状态已在其他设备更新”错误。

登录态测试使用两个机器各自的受控本机 HTTP 服务，验证真实 HttpOnly Cookie 恢复与服务端认证读取。这不替代任意第三方网站的登录、设备绑定或风控验收。两端测试均连接专用本地验收 API，正式后端尚未部署本轮改动。

## 修复

1. 多标签关闭时，主程序先采集完整会话，再清空 context 并关闭标签。晚到的 `pagehide` 原先会将 sessionStorage 快照重排为空。关闭期间现在不再接受该回调覆盖已采集快照；真实双向恢复与三项回归通过。
2. Windows 写入的 OPFS 元数据包含反斜杠路径，原封复制后 Mac 找不到实际文件。现在在 Chromium 完全停止后，用原系统和原内核读取隔离临时副本，导出逻辑目录与文件字节；恢复端在业务页加载前通过 origin 内的存储 API 重建。临时副本阻止站点脚本、Service Worker 和外部请求，完成后清理。

文件快照校验 origin、目录拓扑、重复名称、大小、Base64 与 SHA-256。限额为 100 个 origin、2000 个条目、单文件 4 MiB、总文件 12 MiB；超限或导出失败会保留原档案并报告失败，不将空快照当成完整成功。当前覆盖 `navigator.storage.getDirectory()` 暴露的默认 origin 文件系统；命名 Storage Buckets 未验收。没有新增逻辑文件快照的旧版本档案仍走原协议，跨系统迁移前应在新版本的原设备保存并关闭。

Chromium 的文件元数据使用平台文件路径序列化，相关实现见 [Chromium 官方源码](https://chromium.googlesource.com/chromium/src.git/+/refs/heads/main/storage/browser/file_system/sandbox_directory_database.cc)。本轮根因也由实际档案字节及两端恢复结果核对。

## 实际指纹差异

验证网站根据真实信号计算身份，不使用 UUID、标签、IP、Cookie 或 URL 参数参与身份哈希。[查看本轮采样](http://192.168.50.221:19090/?run=sync-20261013-0747)。

| 内核 | Mac 指纹前 16 位 | Windows 指纹前 16 位 | 返回 Mac |
| --- | --- | --- | --- |
| 140 | 7bfaea8ce3aaccf7 | 485f355212f95315 | 与初次 Mac 相同 |
| 144 | a80ba599028c21e8 | 30fb7442a912523f | 与初次 Mac 相同 |

默认自动硬件设置随本机变化：Mac CPU 并发数为 8、色深为 30；Windows 为 4、24。Canvas 导出、像素与 Audio 哈希也不同。该样本的 WebGL、ClientRects、UA、platform、语言及时区相同。同步指纹 seed 并不会统一两套操作系统的原生绘制、音频和硬件属性；跨系统指纹一致仍是明确未完成项。
