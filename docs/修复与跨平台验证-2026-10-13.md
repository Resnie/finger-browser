另外补齐了两项收尾修复：

- Windows 长目录下 CacheStorage 的原生索引读写失败：仅当档案路径较长时建立随机的短 junction 入口；原用户目录及归属校验保留。进程匹配校验入口仍指向当前档案，并精确匹配 `--user-data-dir`，进程停止后仅 unlink 入口。真实 Windows 云端恢复及入口清理通过，Mac / Windows 各 5 项目录绑定与进程匹配测试通过。
- macOS 构建增加 ZIP 目标，生成包含 ZIP 与 DMG 的更新清单，两个文件的 SHA-512 与清单逐项一致，证据见 `mac-update-artifacts.json`。ZIP 是 macOS 自动更新的要求，参见 [electron-builder v26 官方文档](https://www.electron.build/v26/docs/features/auto-update/)。本地产物验证不替代正式发布和签名验收。
