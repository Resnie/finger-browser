## 本轮修复的关键问题

- 旧谷歌密钥缺少受确认约束的迁移流程；账号迁移并发可能覆盖已配置值，删除后重设存在 ABA 风险。
- 用户名后端支持 100 字符，客户端却限制 20，造成有效账号无法登录。
- 浏览器退出前上传快照遗漏退出后才刷盘的原生资料；同 URL 多标签关闭顺序可能保存旧临时存储。
- 启动存储 bootstrap 临时页面的空检查点覆盖了云端 session 恢复队列；跨源 iframe 可伪造检查点。
- 禁用扩展在换机恢复时被重新启用；不稳定扩展标识和不支持的原生组件缺少明确提示。
- 旧客户端携正确版本号仍会过滤新版 state 字段，两条保存入口均新增同一行锁下的完整性保护；无版本号也不能覆盖，拒绝时所有字段和版本均保持不变。
- 邮件 UID/排序、断流、POP3 超时以及非验证码数字提取的边界不完整。
- 发布版本比较的 NaN 绕过、缺少 07/08 数据库前置、缺失应用图标资产。

## 恢复边界

云端保存账号资料、谷歌密钥、窗口配置、关联、页面、历史、自定义凭据、标准网站存储和白名单原生档案。本机目录可以重新生成，不需要复制原电脑的 Electron safeStorage 密钥。

真实指纹验收只说明本机 Chromium 页面中的属性与设置生效，不代表所有网站反检测保证。WebRTC 本轮未使用公网 STUN/TURN；字体只验证 `fonts.check` 限制，不是完整字体渲染隔离；worker、OffscreenCanvas 和跨物理操作系统仍未验证。

不承诺跨系统恢复 Chromium 自己的 OS 加密密码库、设备私钥、任意下载文件、原生扩展组件或全部浏览器内部文件；应用管理的网页账号密码不受该限制。原生档案上限为 12MiB、单文件 4MiB、2000 文件、50 个纯 JS MV3 扩展；超限明确报错，不声称已完整云同步。恢复队列使用 CAS，未安全同步的资料不会静默当作成功。
