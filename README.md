# 指纹浏览器

## 功能

- 创建不同指纹的浏览器
- 管理已创建的浏览器实例
- 浏览器实例分组
- 创建浏览器时选择内核
- 浏览器代理设置
- 支持手动添加cookie
- 支持编辑浏览器实例
- 更新由对象储存改为git
- 浏览器分组展示管理界面
