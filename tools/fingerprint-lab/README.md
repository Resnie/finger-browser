# 局域网指纹验证网站

在项目目录运行：

```bash
FINGER_LAB_HOST=192.168.50.221 npm run fingerprint:lab
```

当前部署地址为 `http://192.168.50.221:19090/`，同一局域网的 Mac 与 Windows 无需登录即可访问。服务进程需要保持运行；局域网 IP 变化后需修改绑定地址。

新建浏览器窗口时打开“自动指纹”，访问网站，为每个窗口填写不同标签，并使用相同的测试批次。第一次采集后关闭并重新打开同一窗口，保留标签再采集；同一窗口的 ID 应保持稳定，不同窗口应显示不同 ID。也可以打开多个标签页验证同一窗口的稳定性。

网站从真实 Canvas 导出、像素读取、离线音频、WebGL、布局和环境属性计算 SHA-256。窗口标签、Cookie、IP、URL 参数和采样时间不参与身份计算。分别显示组件哈希、Worker / iframe 检查及代理路由证据；可导出 JSON。采样保存为 JSONL，服务重启后读取已有记录。

采样默认保存在 `tools/fingerprint-lab/evidence.local/`，由已有 Git 忽略规则排除；`FINGER_LAB_EVIDENCE` 可指定其他目录。临时测试包传输、测试代理接口与测试报告上传仅在显式设置 `FINGER_LAB_ARTIFACTS` 时开启，且只允许指定的 Mac 和 Windows 测试机；正常启动均关闭。网站本身允许局域网访问。代码不包含公网部署或自动开机启动配置。

自动指纹保证的是这些实际采样能区分测试窗口，不能代表任意第三方网站所有识别规则都无法关联窗口。Worker 适配依赖固定的 Playwright 1.55.0；升级依赖后必须重新执行 Worker、CSP 和公开 CDP 事件回归。
