# Shared fingerprint font

Noto Sans SC Regular, upstream Sans2.004, from [Noto CJK](https://github.com/notofonts/noto-cjk/tree/Sans2.004). Original source: https://raw.githubusercontent.com/notofonts/noto-cjk/Sans2.004/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf

The WOFF container uses the same font tables and outlines, without subsetting or glyph modification. It is bundled for offline rendering; websites do not download this font from a public service. See `OFL.txt` for the upstream license. Canvas text paths are parsed with the pinned MIT-licensed OpenType.js 2.0.0 dependency. Website-loaded fonts, styled text and unsupported glyphs retain native drawing.
